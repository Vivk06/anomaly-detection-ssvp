# Curated results

`metrics.csv` and `captions.csv` transcribe the source reports on their original scales. Blank metric cells mean the source did not report that field. Run IDs serve as labels; the CSVs do not point to old run folders. `tables/` is generated by `scripts/reporting/render_tables.py`.

Raw evidence retained here includes WinCLIP per-image clean and noisy CSVs, the two WinCLIP summary files, ten run22 caption reports, and the ablation summary. The separate WinCLIP source rows are labelled in `metrics.csv` and [their own table](tables/winclip_summary.md); they are excluded from the README selected comparison. WinCLIP score maps were omitted. Reported numbers are treated as verified.

## Known issues

- The SSVP `heavy_v1` protocol applies Gaussian noise 0.25, blur sigma 2.0, salt-and-pepper probability 0.03, and JPEG quality 20. WinCLIP's `winclip_gauss020` applies Gaussian noise 0.2 to normalized tensors. The noisy rows use different protocols.
- The dated WinCLIP 240, 336, and 518 reports list pixel PRO as 0.00 for all three categories. The separate summary files report different pixel PRO values for some categories.
- WinCLIP cable image AUROC is around 44.6 in the 240-pixel and summary sources; the low value remains an open interpretation issue.
- The origin of `raw/winclip/summary_winclip.csv` and `.json` differs from the `winclip_clean` and `winclip_noisy` per-image CSVs. The separate top-level summary source was retained without reconciling scores.
- The caption F1 of 1.0 for deterministic synthesis uses references designed to match the generated phrasing. It is an upper bound for text matching.
