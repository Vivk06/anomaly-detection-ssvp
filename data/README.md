# Sample images and MVTec AD data

`data/samples/` contains eight unique cable images copied from the source example folders. The two `sample_*.png` images came from the uncategorized sample inputs and sit under `data/samples/combined/` for demonstration; no defect label is asserted for them.

Supply MVTec AD separately. `data/mvtec/` is created at runtime when you prepare the 70/20/10 cable resplit. This repository contains no dataset download or model weights.
